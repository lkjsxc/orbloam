# Orbloam contributor contract

Orbloam is a shared, cooperative browser colony game. Preserve the user's circle-based visual language, mouse-first controls, one shared resource world, approximately one-hour resident lives, persistent research, and substantial industry.

## Authority and execution

Use the unchanged pinned official lkjscript runtime. Gameplay, admission, commands, persistence and HTTP are graph-owned. `project/HEAD` and its canonical objects are the accepted program; `dist/application.lkja` is an execution artifact. Python only authors public compact requests or tests. Do not introduce a Python/Node backend, patched runtime, FFI helper, client-awarded resources, a hidden hosted service, or handwritten binary/pack mutations. Use public `change plan` / `change apply` and retain the actual requests and reviewed plans.

The source generators produce a fresh graph with fresh identities; they are not a second live authority. Prefer reviewed changes to the accepted graph for continued development. Re-creation requires explicit schema/transport compatibility checks. Never regenerate an accepted project silently during startup or CI.

## Correctness

Retain exact chronological 10-second economic ticks. Birth slots, one-hour deaths, roles, shared scarcity/regrowth, input consumption, maintenance, ownership and action receipts are deterministic new-version rules. Cosmetic interpolation is not physical simulation. Never hide backlog, skip elapsed time, silently delete residents/depleted resources, or market a new model as an identical-workload speedup of the predecessor.

A successful response must follow committed native transaction completion. Preserve registration retries, bearer-key confidentiality, explicit sequence conflicts and replay of the exact uncertain intent. Do not replace type/JSON errors with a fresh world. Do not migrate/delete saves automatically. An absent-root logical restore must be verified before an operator switches the descriptor.

## Delivery

Keep a runnable artifact and accepted graph in version control, not only temporary chat/CI links. Do not commit live or test saves, secrets, recovery keys, caches or downloaded runtime binaries. Include the runtime's licenses in offline playable packages. Retain the original repository LICENSE.

Run focused native HTTP and independent enumerative tests before the final full graph check/build. Measure actual native performance, bind evidence to artifact/runtime hashes and disclose seeded fixtures. Do not conflate browser bridge tests with normal navigation/CSP/CORS/TLS/storage acceptance. Keep CI finite and avoid repeated full compilation for cosmetic changes.

Remote `main` delivery is complete only after a read confirms the accepted commit is on remote `main`. A local commit, bundle, topic branch or Actions artifact is not that delivery. Respect concurrent remote work; never force-push, disable protection, or bypass missing write permissions. Give a precise remaining handoff when access is unavailable.
