# Evidence map

Current Quiet World evidence is bound to the application hash in `dist/BUILD.json`.

Current: `acceptance.json`, `catalogue.json`, `rebuild.json`, `standalone.json`,
`performance.json`, and `quiet-world/` (native journey, presentation tests, clean
check, browser report, and screenshots).

Historical: `build/`, `browser/`, `browser-pilot/`, `history/`, and `remote.json`.
Those retain the reconstruction/pilot bytes and observations; a recent file copy
is not proof of a recent test. In particular, the old remote-main observation is
not the current repository status. Current documentation does not use it to claim
a remote publication. See `docs/VERIFICATION-20260920.md` for the prior report.

No file in this directory is a live save or a recovery-key backup. Test stores and
credentials remain outside distribution.
